# Nova Landing Page

Landing page moderna desenvolvida com React, TypeScript e Three.js.

## Instalação

```bash
npm install
```

## Como rodar

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Deploy no GitHub Pages

```bash
npm run deploy
```

## Tecnologias

- React 19
- TypeScript
- Vite
- Three.js
